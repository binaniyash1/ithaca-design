# Onboarding — using Ithaca after install

1. Open the **product repo** you want UI in (not this marketplace repo).
2. Confirm Ithaca is loaded (`/ithaca-design` or Claude plugin after restart).
3. Paste a PRD or point at a file such as `tests/sample-prds/crm-today.md`.
4. Ask:

```
Use the Ithaca Design skill. Build this PRD as production-ready product UI.
```

Every reply should open with `Using Ithaca Design v…`. If that line is missing,
restart / reinstall.

See [INSTALL.md](INSTALL.md) for install and verify.
