# Sample PRD — Notification settings

```
Use the Ithaca Design skill. Build this PRD as production-ready product UI.
```

## Primary user

Account owner configuring how the product contacts them.

## Job

Choose which email and in-app notifications they receive, per category.

## Requirements

- Settings page (high density) inside an app shell if the repo has one
- Rows of notification categories, each with an on/off switch
- Saving is implicit on toggle
- States: loading, all enabled, mixed, permission denied, failed to load

## Out of scope

Billing, password reset, marketing landing page.
