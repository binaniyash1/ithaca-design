# Ithaca foundation stubs

Stub pointers for agents and humans. The load-bearing rules for generation live
in `skills/agent/references/foundations.md`. Final tokens and component
contracts land in later phases.

## Density modes

| Mode | Use for | Depth |
|---|---|---|
| High | Dashboards, tables, settings, queues | Hairline borders, no shadow |
| Low | Onboarding, empty states, marketing, agent focus | Soft shadow on surface, optional wash |

Never mix modes on one surface.

## Empty states

Treat first-run, filtered-empty, and failed-to-load as three different outcomes.
See also `spec/empty-states.md` in this repo when authoring the full system.
