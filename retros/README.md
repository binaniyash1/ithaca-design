# Retros

One file per phase, committed at the end of that phase: `phase-N.md`.

Three questions, three answers. Per the execution plan, Part D:

1. What took longer than estimated, and what specifically was underestimated?
2. What did the validation gate catch that you would have shipped?
3. What rule is missing that you only discovered by looking at output?

Question three is how the rules layer actually gets built — not by planning, but
by generating, wincing, and writing down why.

Skipping these is how phase five repeats phase two's mistake.
