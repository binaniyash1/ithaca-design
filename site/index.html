Install

Paste both lines into Claude Code, one after the other:

/plugin marketplace add binaniyash1/ithaca-design
/plugin install ithaca-design@ithaca

The repository is private while the system is being built. If the first line fails with a not-found error, you need read access — ask Yash.

Then turn on auto-update

This step is not optional, and skipping it fails silently. Local and third-party marketplaces ship with auto-update off, so without it your catalogue never refreshes and you sit on an old version indefinitely with no error to tell you.

  1. Run /plugin
  2. Open the Marketplaces tab
  3. Select ithaca
  4. Choose Enable auto-update

No terminal? Paste this instead

You do not need to know what any of the above means. Open Claude Code and paste this message as if you were talking to it: 

Please install the Ithaca Design plugin for me.

Add the marketplace binaniyash1/ithaca-design, then install
the plugin ithaca-design@ithaca, then enable auto-update for
the ithaca marketplace.

Tell me each command before you run it, and tell me when I
need to restart.

If it reports that the repository cannot be found, you do not have access yet — that is the only likely failure here.

Restart before you test it

The plugin will not work in a session that was already open.

Skills load when a session starts, so a session running during the install knows nothing about it. Quit Claude Code and reopen it, or run /reload-plugins in the open session. If that warns about the prompt cache, run /reload-plugins --force.

Testing before restarting is the single most common way to conclude the plugin is broken when it installed perfectly.

One quirk worth knowing: the reload summary counts only commands, so it can report 0 skills even when the skill loaded correctly. Ignore that number and use the check below instead.

Verify it worked

Start a fresh session and type exactly this:

design me a settings page

The reply must open with this line, word for word:

{{ANNOUNCE}}

Read the result like this:

  • Line is there, version matches above — working, and current.
  • Line is missing entirely — the plugin did not load. You almost certainly did not restart.
  • Line is there but the version is older than {{VERSION}} — your install is stale. Auto-update is off, or has not run yet.

At version {{VERSION}} the skill is a canary: it announces itself, tells you the design system is not authored yet, and asks what you were trying to build. It cannot generate a screen, and it will refuse rather than improvise one. That refusal is the feature.
