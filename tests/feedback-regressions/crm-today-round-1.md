# CRM Today — feedback regression 1

Source: first rendered CRM Today screen review, 28 August 2026.

This is an observable regression checklist, not a replacement PRD.

- Navigation product block is about 20% shorter and remains aligned with the
  main shell.
- Independent attention groups are visually separated without becoming a card
  wall.
- Expanded rows use stable columns for identifier, description, source/status,
  age/value, hover actions, and the dominant row action.
- Long values truncate predictably; all ages and equivalent metadata align.
- Selected rows use a pale full-row blue tint and no thin blue side rail.
- Accordion headers and selectable row bodies are fully clickable; nested row
  actions operate independently.
- Secondary buttons, tabs, row actions, and menu options hover with a very light
  neutral fill, never a filled brand blue.
- Every clickable target uses the pointer cursor and has visible keyboard focus.
- Outlined buttons, dropdown triggers, and menus use quiet neutral borders.
  Dropdown surfaces are 4–8px rounder than their compact triggers.
- Completing an item can remove its row, but success/undo feedback overlays the
  page and causes no vertical layout shift.
- Currency, percentages, counts, timestamps, and identifiers use the mono
  treatment.
- Pipeline composition uses colourful, consistently mapped segments, pale
  tracks, aligned labels, sufficient spacing, and a target tick where relevant.
